# Automate Me (個人化模式技能萃取)

引導將使用者的工作習慣、溝通風格與工程慣例提煉為專屬的 `-mode` 技能（例如 `chen-mode`），讓後續 Agent 能完全契合使用者的協作風格。

## 執行流程

### 0. 檢查現有技能
檢查工作區或全域配置中是否已存在對應的 `*-mode/SKILL.md`：
- 若已存在，詢問使用者是「更新現有技能（預設）」還是「重新建立」。

### 1. 挖掘工作習慣與偏好
分析近期在工作區中的互動模式，關注以下信號：
- 回覆風格（長度、語調、排版、繁體中文等格式要求）。
- 委派習慣（何時調度 Subagent、平行度偏好、多角色審查要求）。
- 驗證態度（如何定義「完成」、測試與手動驗證要求）。
- 代碼與寫作規範（遵守的原則、Lint 工具、註解限制）。
- 流程慣例（分支管理、Commit 規範、PR 流程）。

### 2. 結構化確認
透過問答確認挖掘到的偏好，聚焦在最重要的核心規則。

### 3. 起草技能 (Draft Skill)
在 `.agents/skills/<handle>-mode/SKILL.md` 或專案技能目錄中撰寫技能檔案：
- 包含標準 Antigravity YAML Frontmatter (`name`, `description`)。
- 遵循繁體中文與清晰簡短的原則撰寫各章節。
- 引用既有原則技能（如 `principle-laziness-protocol` 等），避免冗長重複。

### 4. 檢閱與落實
向使用者展示草稿，收集回饋並進行精簡修飾，確認後存入專案。
