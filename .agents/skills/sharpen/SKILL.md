# Sharpen (需求深度打磨與提示詞重寫)

我想要的是這個任務的「更深版本（deeper）」，而不是「更大版本（bigger）」。在重寫我的提示詞之前，請先回答以下四件事：

1. **專家視角**：這個領域的頂尖專家在處理這件事時，會多做哪件我沒要求但極其關鍵的事？
2. **第一手素材**：他們會從哪個最原始的第一手素材（rawest material）開始分析，而不是依賴已經幫我消化過的二手摘要？
3. **具體方法與工具**：他們會使用哪些具體的方法與工具來推進？
4. **客觀檢驗信號**：除了你或我的主觀判斷之外，什麼外部客觀信號能證明最終結果是正確的？

回答完這四點後，將我的原始提示詞重寫為一份精確要求上述深度的指令。

屬於我（人類操作者）應該決定的取捨與偏好，請保持開放讓我選擇，不要替我預先做決定。
