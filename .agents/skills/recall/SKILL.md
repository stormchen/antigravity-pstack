# Recall (工作脈絡重建)

在開始或繼續工作之前，快速重建近期的工作上下文，產出清晰緊湊的現況摘要與下一步建議。

## 執行步驟

1. **確認範圍**：明確鎖定時間範圍（預設最近 7 天）與指定的主題、功能或分支。
2. **檢視執行記錄與會話歷史**：在當前工作區範圍內檢索相關對話、決策記錄與產物。若資料量大，可透過 `invoke_subagent` 平行檢索。
3. **查詢共用歷史與版本控制**：調用 `git`、`gh` 或相關工具檢查分支、PR 狀態、最近提交以及相關的 Issue 討論。
4. **驗證實際狀態 (Live State)**：以真實的代碼與 Git 狀態為準，避免依賴過期的摘要。
5. **輸出摘要簡報**：產出結構化現況簡報。

## 輸出結構

- **核心總結 (Capsule)**：最多 5 點，說明這項工作是什麼以及整體進展到哪裡。
- **工作線狀態 (Threads)**：每條工作線一行，標明狀態（如 `[merged #N]`、`[open PR #N]`、`[in flight <branch>]`、`[verified, uncommitted]`、`[planned]`）。
- **待解決問題 (Problems)**：列出遇到的主要阻礙或反覆出現的異常。
- **下一步行動 (Next Move)**：最重要且具體的下一步操作。
