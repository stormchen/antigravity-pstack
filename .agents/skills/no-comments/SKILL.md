# No comments (代碼註解清理)

清理代碼庫中不必要的冗贅註解。代碼作者往往傾向保留過多敘述性註解，本技能以客觀視角審查並剔除無效註解，同時將真正的約束轉化為型別、測試或 Lint 規則。

## 審查範圍

以使用者指定的檔案/Diff 為準；若未指定則使用當前分支對比 base branch（預設 `main`）的完整變更。

## 執行流程

1. **掃描註解**：檢視變更範圍內的所有註解。
2. **分類識別**：
   - **必須刪除 (MUST KILL)**：複述代碼做什麼的流水帳註解（如 `// Phase 1: add cards` 或 `// increment counter`）、已被重構淘汰的過期註解、死代碼註解。
   - **應保留 (KEEP)**：說明非直觀設計動機、外部系統特殊 Bug 或標準規範限制的關鍵原因（說明「Why」而非「What」）。
3. **約束結構化 (Encode Lessons in Structure)**：
   - 若註解聲明了重要約束（如「請勿修改此處順序」），優先考慮將其轉換為型別限制、單元測試斷言或 Linter 規則（遵循 **encode-lessons-in-structure** 原則），隨後刪除原註解。
4. **清理執行**：
   - 刪除所有判定為冗贅的註解，保持代碼簡潔純粹。
5. **產出報告**：條列清理的註解數量、保留的關鍵動機註解以及轉化為結構化防護的項目。
